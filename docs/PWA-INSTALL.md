# 把 DSH 添加到手机/电脑主屏幕（免安装方案）

DSH 官方网页自带 PWA manifest（应用清单），任何设备不用装 App，浏览器打开、
登录、添加到主屏幕，就能得到一个全屏图标。

> 仓库里 `pwa/` 目录的旧 PWA 客户端已归档（它依赖旧的 Basic Auth 认证体系，
> 当前认证体系下不可用），本页是现行的免安装做法。

## 安卓 / 鸿蒙（浏览器）

1. 用浏览器打开 DSH 地址（家庭直连地址或公网固定域名，如
   `https://your-domain.de5.net`）；
2. 打开浏览器菜单（一般右上角「···」）；
3. 选择 **「添加到主屏幕」** 或 **「安装应用」**；
4. 确认添加——之后从主屏幕图标打开，全屏运行。

## iPhone / iPad（Safari）

1. 用 Safari 打开 DSH 地址；
2. 点底部「分享」按钮；
3. 选 **「添加到主屏幕」** → **「添加」**。

## 电脑（Chrome / Edge）

1. 打开 DSH 地址；
2. 地址栏右侧出现「安装」图标（或菜单里选「安装 DSH Remote」）；
3. 点击安装。

## 提示

- 首次打开若停在登录页，用登录插件的账号密码登录一次即可（30 天内免登）；
- 公网固定域名经隧道反查，地址变了也不用在主屏幕上改任何东西。
